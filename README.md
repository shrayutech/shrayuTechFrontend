## ⚙️ Getting Started

Follow these instructions to run the project locally.

### Prerequisites

Install the following software:

- [Node.js](https://nodejs.org/)
- npm, included with Node.js
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/shrayutech/shrayuTechFrontend.git
```

**2. Navigate to the project directory**

```bash
cd shrayuTechFrontend
```

**3. Switch to the project branch**

```bash
git checkout project
```

**4. Install dependencies**

```bash
npm install
```

**5. Start the development server**

```bash
npm run dev
```

Open the local URL shown in your terminal to view the website.

## 🏗️ Production Build

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🧹 Code Quality

Run the configured ESLint checks:

```bash
npm run lint
```
